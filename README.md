# Tributo Claro — Calculadora de Transição Tributária

Projeto estático, sem Node, sem npm, sem pnpm e sem dependências de build.

## Deploy na Vercel

1. Suba estes arquivos para um repositório GitHub.
2. Na Vercel, importe o repositório.
3. Não informe Framework Preset.
4. Build Command: deixe vazio.
5. Output Directory: deixe vazio.
6. Faça o deploy.

A Vercel servirá o `index.html` diretamente.

## Arquivos

- `index.html` — estrutura da aplicação.
- `style.css` — visual responsivo.
- `script.js` — cálculos e interações.
- `vercel.json` — configuração mínima da Vercel.

## Observação

A calculadora é uma simulação matemática informativa e não constitui apuração fiscal.
